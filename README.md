# MiniCars website

Privacy policy and support page for the MiniCars iOS app, served by GitHub Pages
at https://minicarsapp.github.io.

The pages (`index.html`, `privacy/`, `support/`, `ru/…`, `404.html`) are generated:
edit `tools/build.py`, then run

```bash
python3 tools/build.py .
```

The support form posts to Web3Forms, which forwards messages to the support
mailbox.
